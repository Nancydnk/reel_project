# Final Project Video Reel Agent

This project contains an automated agent built for Homework 2 that converts a project proposal into structured slides, critiques, and artifacts for grading.

## How to Install & Run

1. Clone or download this repository.
2. Install the required dependencies:
   ```bash
   pip3 install -r requirements.txt
3. Set your `OPENAI_API_KEY` in a local `.env` file if using external OpenAI services.
4. Run the main agent script:
   ```bash
   python3 reel_agent.py
